INTERIORSYNC - FRONTEND-ONLY DEPLOYMENT
=======================================
This package is already compiled, plain HTML/CSS/JavaScript.
No Node.js build, React, npm, backend, or database is required to host this demo.

IMPORTANT: Upload THE CONTENTS of this folder to your GitHub repository root.
The repository root must contain index.html, runtime.js, app.js, mock-api.js,
styles/, assets/, and vercel.json. Do not upload the ZIP itself as the website.

GITHUB PAGES:
1. Create/open your GitHub repository and upload all files and folders in
   this directory to the main branch, at repository root.
2. On GitHub: Settings > Pages > Build and deployment.
3. Set Source: Deploy from a branch; Branch: main; Folder: /(root); Save.
4. Visit https://YOUR_USERNAME.github.io/YOUR_REPOSITORY/
   (or https://YOUR_USERNAME.github.io/ for a user-site repository).
5. InteriorSync routes use URL hashes for GitHub Pages, for example
   https://YOUR_USERNAME.github.io/YOUR_REPOSITORY/#/admin/dashboard
   This allows navigation and refreshing pages without 404 errors.

VERCEL:
1. Import the GitHub repository into Vercel.
2. Framework Preset: Other; no build command; root directory: ./
   (or the appropriate frontend folder if kept nested).
3. Output directory: leave default or set to . (project root).
4. Deploy. vercel.json allows direct visits to frontend routes.

DEMO LOGINS (any nonempty password):
- client@demo.local: Client
- designer@demo.local: Interior Designer
- manager@demo.local: Project Manager
- admin@demo.local: Administrator

LIMITATIONS:
- The login is a demonstration only, NOT secure authentication.
- Data changes are saved in each browser's localStorage, NOT a shared database.
- The original asset bundle did not include login-interior.png and
  dashboard-banner.jpg, so these CSS background images are missing.
- This does not provide real backend, storage, file uploads or approvals.

This deployment package keeps the uploaded source and UI, while flattening the
folder structure and adding hosting-compatible routing and configuration.
